# Clinical visual assets

The illustrations in this directory are newly authored local SVG UI artwork matched to the owner-approved A-Health unified UI board. They are decorative, not clinical visualizations or data. `followup.webp` is cropped from the owner-supplied AI-generated design board; people pictured are illustrative, not AHP users or testimonials.

No external requests, licensing dependency, patient photos or remote tracking are used. All files are for presentation only. Clinical records never use these images as evidence.
